# ReviewDNA v0.1.0

ReviewDNA v0.1.0 is the first tagged pre-v1 GitHub Action release. It turns Pull Request and code-review history into evidence-backed engineering conventions while keeping every inferred rule traceable to source review evidence.

## Highlights

- Deterministic, local-first review mining with explainable confidence, scope, lifecycle, conflict, and evidence provenance.
- Incremental GitHub collection, validated resumable pipeline checkpoints, and Watch-mode deltas for recurring repository analysis.
- Review-thread evidence dispositions, CODEOWNERS-aware weighting, human decisions, and conservative rule evolution/supersession tracking.
- Documentation coverage and drift checks across common agent/contributor instruction files, with optional semantic matching.
- Optional semantic clustering plus separate Ollama/OpenAI-compatible wording refinement; remote providers remain explicit opt-in.
- Privacy controls for reviewer/path/evidence redaction and targeted common secret/PII scrubbing; redaction disables raw cache/checkpoint persistence.
- User-priced token/cost preflight and remote-cost budget enforcement for optional remote stages.
- Evidence-backed Knowledge Proposal bundles and explicit dry-run-first GitHub Pull Request publishing without overwriting repository policy files.
- Static dashboard with Review Hotspots, deterministic Automation Opportunities, rule evolution, documentation provenance, and a downloadable 1200×630 SVG share card.
- Reproducible synthetic public-demo artifact built by the real ReviewDNA engine.

## GitHub Action

Use the immutable release tag:

```yaml
- uses: ahmed2qaid/reviewdna/action@v0.1.0
  with:
    repository: owner/repo
    max-prs: '100'
    min-evidence: '2'
```

For security-sensitive workflows, pinning the exact release commit SHA remains the strongest supply-chain choice.

## Distribution note

This release tags the repository and its composite GitHub Action. ReviewDNA is **not published to npm/npx yet**; install/run it from the repository until the package surface and registry publishing workflow are finalized.

## Compatibility

ReviewDNA remains pre-v1. The analysis schema is currently `1.0`, but CLI, fingerprint, package, and extension contracts may still evolve before ReviewDNA 1.0 stable.
